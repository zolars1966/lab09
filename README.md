### Задание 1 **(2)**

```
print(l, d)
```
Выводит список `l` целиком и словарь `d` целиком как объекты:
```
['Утопия', 14, 'Вселенная', 25] {'sep': ',', 'end': '\n'}
```

```
print(*l, d)
```
`*l` распаковывает список — элементы передаются как отдельные позиционные аргументы. `d` передаётся как один объект (словарь). Итог: четыре элемента списка, затем словарь:
```
Утопия 14 Вселенная 25 {'sep': ',', 'end': '\n'}
```

```
print(*l, *d)
```
`*l` распаковывает список, `*d` распаковывает словарь — при распаковке словаря через одну звёздочку берутся его ключи (`'sep'`, `'end'`):
```
Утопия 14 Вселенная 25 sep end
```

```
print(*l, **d)
```
`*l` распаковывает список в позиционные аргументы, `**d` распаковывает словарь в ключевые аргументы `sep=','` и `end='\n'`. Поэтому элементы списка печатаются через запятую, а в конце — перевод строки:
```
Утопия,14,Вселенная,25

```

###  Задание 11 **(2)**

- В `toint` передаётся **функция** `fun` (вызываемый объект).
- `toint` возвращает **новую функцию** `wrapper` — обёртку над `fun`.
- `wrapper(*args)` принимает произвольные позиционные аргументы, преобразует каждый в `int` с помощью `map(int, args)`, распаковывает результат звёздочкой и вызывает исходную `fun` с этими целыми аргументами.

Примеры:

```python
add = toint(lambda a, b: a + b)
print(add('2', '3'))          # 5

mul = toint(lambda a, b, c: a * b * c)
print(mul('2', '3', '4'))     # 24

print(toint(max)('10', '3', '7'))   # 10
print(toint(pow)('2', '10'))        # 1024
```

### Задание 1 **(3)**

Декоратор — это функция, которая принимает функцию и возвращает новую функцию (обёртку). Синтаксис `@decorator` применяет декоратор к функции при её определении. `toint` уже имеет нужную сигнатуру: принимает функцию, возвращает `wrapper`.

```python
@toint
def add(a, b):
    return a + b

print(add('2', '3'))    # 5

@toint
def mul(a, b, c):
    return a * b * c

print(mul('2', '3', '4'))   # 24

@toint
def pow_(a, b):
    return a ** b

print(pow_('2', '10'))  # 1024
```

Здесь `@toint` эквивалентно `add = toint(add)`. Внутри `wrapper` аргументы приводятся к `int`, затем вызывается исходная функция.

### Задание 3 **(5)**

```python
def fib(n):
    def hlp(k):
        # возвращает (F(k), F(k+1))
        if k == 0:
            return (0, 1)
        a, b = hlp(k // 2)
        c = a * (2 * b - a)
        d = a * a + b * b
        if k % 2 == 0:
            return (c, d)
        else:
            return (d, c + d)
    return hlp(n)[0]
```

Здесь глубина рекурсии — O(log n), что для `n = 1000` около 10 вызовов. Используются тождества на множестве чисел Фибоначчи.

### Задание 4 **(9)**

Строим строку-выражение рекурсивно:

- `n == 1` => `"x"`
- `n` чётное => `"(" + expr(n//2) + "**2)"`
- `n` нечётное => `"(x*" + expr(n-1) + ")"`

```python
def fastpow(n):
    def expr(k):
        if k == 1:
            return "x"
        if k % 2 == 0:
            return "(" + expr(k // 2) + "**2)"
        return "(x*" + expr(k - 1) + ")"
    s = expr(n)
    return lambda x: eval(s)
```

Проверка:

```python
pow10 = fastpow(10)
print(pow10(2))     # 1024
print(fastpow(5)(3))   # 243
print(fastpow(1)(7))   # 7
```
